# Security Policy

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/Pyr0G/competitive-gaming-platform/security/advisories/new) to submit a report to the repository maintainers.

Please report vulnerabilities privately rather than opening a public issue or pull request containing exploit details.

Include:

- The affected page, endpoint, or component.
- The application version or commit, if known.
- Steps to reproduce using test accounts and data.
- The potential impact and any relevant, sanitized evidence.

Do not send passwords, API keys, session cookies, or other people's private data.

## Project status

CGP is under active development. The current implementation and limitations are documented in [README.md](README.md). Include the deployed version or commit in your report so we can identify the affected code.

## Scope

Reports may concern the frontend, backend API, database access, or deployment configuration maintained in this repository. Examples include unauthorized account access, exposure of private messages, privilege escalation, and changes to data without permission.

## Responsible testing

Use a local environment and accounts you control. Contact us before testing a hosted deployment. Avoid accessing other people's data, disrupting the service, or modifying data without permission.

## Handling reports

Maintainers will review reports and coordinate any necessary fix and disclosure with the reporter. Response and resolution times depend on the issue and maintainer availability.
